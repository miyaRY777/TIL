## 学んだこと

### 定数（`const`）の宣言と特徴
分類：JavaScript

#### 定義（結論）
JavaScriptでは、一度代入した値をプログラムの途中で変更（再代入）させたくない場合、`let` の代わりに `const` キーワードを使用して定数を宣言します。

#### 具体例
```javascript
const birthYear = 1995;
// birthYear = 2000; エラーが発生する
```

このように記述すると、`birthYear` という定数コンテナに `1995` が固定され、後から別の値を入れようとするとエラーが起きて安全に保護されます。

#### 要約
- `const` は、再代入したくない値を宣言するときに、`let` の代わりに使います。

### 定数（`const`）の初期化の必須性
分類：JavaScript

#### 定義（結論）
`const` キーワードを使って定数を宣言する場合は、宣言と同時に必ず値を代入（初期化）しなければなりません。後から値を代入することは許されません。

#### 具体例
```javascript
// 正しい書き方（宣言と同時に代入する）
const score = 100;

// 間違い（エラーになる書き方）
const maxSpeed; // 初期化子がないため、この行で SyntaxError
maxSpeed = 120;
```

`let` のように「とりあえず箱だけ作って、値は後で入れる」という書き方が `const` ではできない仕様になっています。

#### 要約
- `const` は、宣言と同時に必ず初期化し、あとから値を入れることはできません。
