## 学んだこと

### インタラクティブ性
分類：JavaScript

#### 定義（結論）
ユーザーの入力や操作に応じて、システムやWebサイトが反応を返す性質のこと。このやり取りは双方向である。

#### 補足
ここで言う双方向とは、次の2つの向きのこと。
ユーザーからシステムへ：ユーザーがボタンをクリックする（入力）
システムからユーザーへ：システムが、そのクリックへの反応を返す（出力）

#### 具体例
```javascript
const button = document.querySelector("button");

button.addEventListener("click", () => {
  document.querySelector("p").textContent = "クリックされました";
});
```

#### 要約
- インタラクティブ性は、ユーザーの入力や操作に応じて、JavaScriptが反応を返す性質のこと。

### `onclick` 属性の役割
分類：JavaScript

#### 定義（結論）
`onclick="..."` は、ユーザーが対象の要素をクリックしたというイベントを検知し、指定されたJavaScriptの処理を実行するための属性です。

#### 具体例
```html
<button onclick="...">Click me</button>
```

ボタンタグの中に記述することで、「このボタンがクリックされたら動く」という予約（イベントの登録）をします。

#### 要約
- `onclick` は、JavaScriptの処理を登録しておき、ボタンがクリックされたときにその処理を実行するための属性です。

### `alert` メソッドの役割
分類：JavaScript

#### 定義（結論）
`alert('Button clicked!')` は、ブラウザ上で警告ダイアログを表示し、指定したメッセージをユーザーに伝えるためのJavaScriptの命令です。

#### 具体例
```javascript
alert('Button clicked!')
```

これが実行されると、画面上に「Button clicked!」というテキストを含んだダイアログが即座に表示されます。

#### 要約
- `alert` は、ブラウザ上に警告ダイアログを表示し、指定したメッセージをユーザーに伝えるためのJavaScriptの命令です。

### 変数の宣言と初期化
分類：JavaScript

#### 定義（結論）
JavaScriptでは、`let` キーワードを使って変数を宣言し、`=` を用いて初期値を設定します。

#### 具体例
```javascript
let age = 25;
```

このように記述することで、`age` という名前のコンテナが作られ、そこに `25` という値が初期化（代入）されます。

#### 要約
- letを使うことで変数を宣言し、その時にイコールを用いることで初期値を設定することができる。

### 変数の再代入
分類：JavaScript

#### 定義（結論）
`let` キーワードで宣言された変数は、すでに値が入っている状態から新しい値に更新（再代入）することができます。

#### 具体例
```javascript
let age = 25;
age = 30; // 再代入
```

最初の宣言時に使った `let` を再度書く必要はなく、変数名だけを指定して新しい値を代入すれば、中の値が上書きされます。

#### 要約
- 変数の再代入をする際には、`let` を使わず、イコールを用いてそのまま値を代入する。

### 変数名の命名規則とベストプラクティス
分類：JavaScript

#### 定義（結論）
変数名は、先頭を数字にしないなどの文法ルールに従う必要があります。コードの可読性を保つために、データの内容を説明する名前を選び、キャメルケースなどの命名慣例に従うのが一般的です。

#### 具体例
- **良い例:** `age`, `points` のような、中身がひと目で分かる説明的な名前。
- **ルール:** 先頭に数字を使うことはできない（例：`1stPlace` はNG、`_score` や `$total` はOK）。
- **キャメルケース:** 複数の単語を組み合わせる場合、最初の単語を小文字にし、続く単語の先頭を大文字にする（例：`thisIsCamelCase`）。

#### 要約
- 変数名の命名規則として、先頭の文字を数字にしない決まりがあり、`_` や `$` などは、先頭の文字に使ってもよい。
- 命名する際に、キャメルケースという慣例があり、2つ目の単語以降は、頭文字を大文字にする。
