# 今日理解できたこと

## レキシカル環境の構成

レキシカル環境は、主に次の2つで構成されている。

### Environment Record

変数や関数などの識別子と、その値を記録している場所。

### Outer Lexical Environment Reference

外側（親）のレキシカル環境への参照。

現在の `Environment Record` に目的の変数がない場合、この参照をたどって外側のレキシカル環境を探す。

つまり、変数が見つからない場合は、外側のレキシカル環境へ順番にさかのぼって検索する。

## コード例

```javascript
function outer() {
  let a = 10;

  function inner() {
    console.log(a);
  }

  inner();
}

outer();
```

## 処理の流れ

1. `outer()` が呼び出されると、`outer` のレキシカル環境が作られる
2. `a` と `inner` が `outer` の `Environment Record` に記録される
3. `inner()` が呼び出されると、`inner` のレキシカル環境が作られる
4. `inner` の中で変数 `a` を探す
5. `inner` の環境には `a` がないため、`Outer Lexical Environment Reference` をたどって `outer` の環境を探す
6. `outer` の環境で `a = 10` が見つかり、`10` が出力される

## 関数を定義したとき

`inner` という関数が作られる。

この関数は、自分がどのレキシカル環境で定義されたかを覚えている。そのため、実行された場所ではなく、定義された場所を基準に外側の変数を探せる。

## 関数を呼び出したとき

`outer()` を呼び出すと、`outer` の新しいレキシカル環境が作られる。

その中で `inner()` を呼び出すと、`inner` の新しいレキシカル環境が作られる。`inner` の `Outer Lexical Environment Reference` には、`inner` が定義された `outer` のレキシカル環境への参照が設定される。
