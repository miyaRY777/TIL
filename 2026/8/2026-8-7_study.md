# 今日理解できたこと

## 変数とは

変数とは、値を入れておくための「名前付きの箱」のようなもの。

JavaScriptで変数を宣言するときは、主に`const`、`let`、`var`を使う。

変数名は自由に決められるが、何を表す値なのか分かる名前にすることが大切。

```javascript
const quantity = 3;
const taxRate = 0.1;
```

## 宣言・初期化・代入・再代入

### 宣言

変数を使うために、名前付きの箱を用意すること。

```javascript
let score;
```

この時点では値が設定されていないため、変数の値は`undefined`になる。

```javascript
let score;

console.log(score); // undefined
```

### 初期化

変数を宣言すると同時に、最初の値を設定すること。

```javascript
let score = 70;
```

### 代入

宣言済みの変数へ値を設定すること。

```javascript
let score;
score = 70;
```

### 再代入

すでに値が設定されている変数へ、別の値を設定すること。

```javascript
let score = 70;
score = 80;

console.log(score); // 80
```

## `let`の特徴

`let`は、あとから別の値を再代入できる変数を宣言するときに使う。

```javascript
let count = 0;

console.log(count); // 0

count = count + 1;

console.log(count); // 1
```

値が変化するカウンターなどに使用できる。

## `const`の特徴

`const`で宣言した変数には、あとから別の値を再代入できない。

```javascript
const score = 70;
score = 80; // TypeError
```

宣言時に初期値が必要で、あとから再代入する必要がない値に使用する。

## `const`で宣言したオブジェクト

`const`で宣言したオブジェクトでも、プロパティの値は変更できる。

```javascript
const user = {
  name: "宮本"
};

user.name = "田中";

console.log(user); // { name: "田中" }
```

これは、変数`user`に別のオブジェクトを再代入しているのではなく、`user`が参照している同じオブジェクトの中身を変更しているため。

一方、変数`user`へ別のオブジェクトを再代入することはできない。

```javascript
const user = {
  name: "宮本"
};

user = {
  name: "田中"
}; // TypeError
```

つまり、`const`で変更できないのは変数への再代入であり、オブジェクトの中身がすべて変更できなくなるわけではない。
