# 今日理解できたこと

## `display`プロパティとは

`display`は、HTML要素の表示方法や、要素同士の並び方を決めるCSSプロパティ。

主な値には、次のようなものがある。

```text
block
inline
inline-block
flex
grid
none
```

## `display: block`

`block`を指定した要素は、基本的に上から下へ縦に並ぶ。

```html
<div class="box">A</div>
<div class="box">B</div>
<div class="box">C</div>
```

```css
.box {
  display: block;
}
```

表示結果のイメージは次のようになる。

```text
[A]
[B]
[C]
```

`block`では、`width`と`height`を指定できる。

## `display: inline`

`inline`を指定した要素は、文章の一部のように左から右へ横に並ぶ。

```css
.box {
  display: inline;
}
```

```text
[A] [B] [C]
```

ただし、`inline`要素には、基本的に`width`と`height`を指定できない。

## `display: inline-block`

`inline-block`は、`inline`と`block`の特徴を組み合わせた表示方法。

```css
.box {
  display: inline-block;
  width: 100px;
  height: 100px;
}
```

要素は横に並びながら、`width`と`height`も指定できる。

```text
[  A  ] [  B  ] [  C  ]
```

## Flexbox

Flexboxは、子要素を主に一方向へ並べて配置するための仕組み。

親要素に`display: flex`を指定すると、その直下にある子要素がFlexアイテムになる。

```css
.parent {
  display: flex;
}
```

### 主軸と交差軸

Flexboxには、次の2つの軸がある。

* 主軸：子要素が並ぶ方向
* 交差軸：主軸と交差する方向

`flex-direction`を変更すると、主軸の向きも変わる。

```css
.parent {
  display: flex;
  flex-direction: row;
}
```

`row`では、子要素が横方向に並ぶ。

```text
[A] [B] [C]
```

```css
.parent {
  display: flex;
  flex-direction: column;
}
```

`column`では、子要素が縦方向に並ぶ。

```text
[A]
[B]
[C]
```

### 子要素の位置を整える

`justify-content`は、主軸方向の配置を整える。

`align-items`は、交差軸方向の配置を整える。

```css
.parent {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 500px;
}
```

この例では、子要素を親要素の中央に配置できる。

### 折り返しと余白

`flex-wrap: wrap`を指定すると、子要素が親要素の幅に収まらない場合に折り返される。

```css
.parent {
  display: flex;
  flex-wrap: wrap;
}
```

`gap`を使うと、子要素同士の間に余白を設定できる。

```css
.parent {
  display: flex;
  gap: 20px;
}
```

## Grid

Gridは、行と列を使って子要素を二次元に配置するための仕組み。

```text
[A] [B] [C]
[D] [E] [F]
```

親要素に`display: grid`を指定する。

```css
.parent {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}
```

`grid-template-columns`は、列の数や幅を決めるプロパティ。

`repeat(3, 1fr)`は、利用できる幅を均等に分けた3列を作るという意味になる。

```text
repeat(3, 1fr)
  ↓
1fr 1fr 1fr
```

Flexboxは主に一方向の配置に向いており、Gridは行と列を使った二方向の配置に向いている。

## `display: none`

`display: none`を指定すると、その要素は画面に表示されなくなる。

```css
.box {
  display: none;
}
```

要素は見えなくなるだけでなく、レイアウト上の場所も取らなくなる。
